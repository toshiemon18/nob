## 目的・背景

design.md のマイルストーンに残っているリンク機能を実装する。仕様は 2026-10-25 に grilling で合意した（Q1〜Q22、Q6a〜Q6d）。

スコープ:
- 本文から `[[...]]` を取り出す
- リンク先を vault のファイルに解決する
- `nob show` に `---links---` 節を足す
- `nob links --unresolved` を追加する

スコープ外: リンクからのノート作成（Neovim フェーズ 2）、バックリンク、リネーム時のリンク書き換え、`nob links` の `--prefix`、全リンクの一覧、キャッシュ。

## 仕様

### 取り出し

- 対象の記法: `[[name]]`、`[[name|別名]]`、`[[name#見出し]]`、`[[name#^block]]`、`![[name]]`
- リンク先は `|` と `#` より前の部分。見出しとブロックの実在は検証しない
- 名前が空のリンク（`[[#見出し]]`）は取り出さない
- 次の範囲は無視する
  - frontmatter。YAML として解釈せず、先頭の `---` から次の `---` までを飛ばす
  - フェンスで囲んだコードブロック（```` ``` ```` / `~~~`）
  - インラインコード（`` `...` ``）
- `%%...%%` と `<!-- -->` は特別扱いしない
- 行番号はファイルの先頭から数える（frontmatter の行も含める）

### 解決

- 照合の前に、ファイル名とリンク先の両方を NFC に正規化し、大文字と小文字を区別しない
- `[[Plan.md]]` は `[[Plan]]` と同じものとして扱う
- `/` を含まないリンクはファイル名と照合する。`/` を含むリンクは、vault 相対パスの末尾と照合する
- `.md` 以外の拡張子が付いたリンク（`[[diagram.png]]`）は、`.md` 以外のファイルからも探す
- 候補が複数あれば、リンクを書いたノートに最も近いものを選ぶ
  - 距離は、ディレクトリを共通の祖先まで上がる段数と、そこから下る段数の和
  - 最小の距離に複数の候補が並べば「曖昧」とし、候補を示す
- 結果は「解決」「未解決」「曖昧」のどれか。どれもエラーにしない

### `nob show`

- タイトルの照合は、NFC と大文字小文字の規則をリンクと揃える。距離の起点がないので、候補が複数あれば今までどおりエラーにする
- リンクがあれば `---links---` 節を出す

```
---links---
[[Plan|計画]]  → projects/Plan.md
[[missing]]    → (unresolved)
[[Note]]       → (ambiguous: a/Note.md, b/Note.md)
```

- リンクは本文に書いたとおりの文字列で出す。同じ文字列は 1 回だけにし、初めて出た順に並べる
- `→` の位置を揃える
- リンクがなければ節を出さない

### `nob links --unresolved`

```
daily/2026-04-30.md:12: [[missing-note]]
daily/2026-04-30.md:15: [[Note]] (ambiguous: a/Note.md, b/Note.md)
```

- 未解決と曖昧のリンクを 1 行に 1 件出す。重複は除かない
- 並びはパス順、同じノートの中では行順
- exit 0（見つかっても成功）
- `--unresolved` なしで実行したら `Error: specify --unresolved` / exit 1

### grilling からの補足（plan 作成時に判明）

- Q19 では「frontmatter が壊れたノートは Warning を出して走査を続ける」と合意した。ただ、取り出しは frontmatter を YAML として解釈しないので、YAML が壊れていても走査には影響しない。警告は出さない
- その代わり、走査で起きうるのは次の 2 つ
  - 閉じの `---` がない frontmatter。Obsidian と同じく、ファイル全体を本文として扱う
  - UTF-8 として読めないファイル。`Warning: skipped <path>: invalid UTF-8` を出して飛ばし、走査は続ける

## 設計

```ruby
# lib/nob/links.rb
Nob::Links::Link = Data.define(:raw, :target, :line)
  # raw    本文に書いたとおりの文字列（"![[Plan|計画]]"）
  # target "|" と "#" より前（"Plan"）
  # line   ファイル先頭からの行番号
Nob::Links.extract(text)  # -> Array<Link>  純粋関数

# lib/nob/links/resolver.rb
Nob::Links::Resolution = Data.define(:status, :paths)  # status: :resolved / :unresolved / :ambiguous
resolver = Nob::Links::Resolver.new(files)   # files: vault 相対パスの配列（全拡張子）
resolver.resolve(target, from:)              # from: リンクを書いたノートの vault 相対パス

# lib/nob/vault.rb
Nob::Vault.name_key(name)          # NFC + 小文字化。照合の規則を 1 か所に置く
Nob::Vault.find_notes(vault, title) # -> Array<String>  show のタイトル解決（resolve_title! の検索部分）
Nob::Vault.files(vault)            # -> Array<String>  全拡張子のファイル（隠しディレクトリは含まない）
```

- `Links` はファイルを読まない（文字列とパスの配列だけを受け取る）。I/O は Vault と CLI が担う
- `Resolver` は照合に `Vault.name_key` を使う
- 例外を投げてエラーにするのは CLI（`resolve_title!` の 0 件 / 複数件）
